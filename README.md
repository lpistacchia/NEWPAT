# NEWPAT

NEWPAT is a collection of bioinformatic tools for prenatal and postnatal paternity testing based on Double Nucleotide Polymorphisms (DNPs) and Single Nucleotide Polymorphisms (SNPs).

The repository includes modules for:

- Fetal fraction estimation
- Prenatal Combined Paternity Index (CPI) calculation
- Postnatal Combined Paternity Index (CPI) calculation
- Fetal sex determination
- Contamination assessment
- SNP calling
- DNP error rate estimation

The modules are designed to operate on data generated by DNPcall and/or SNPcall and can be used independently according to the specific analytical objective.

## Repository Structure

### CPI_from_cffDNA

Fetal fraction estimation and prenatal Combined Paternity Index (CPI) calculation using maternal plasma cfDNA and putative father samples.

The module supports both DNP-based and SNP-based analyses, with configurable fetal-read thresholds based on absolute read counts and/or relative read percentages.

It generates CPI distributions, plots and summary tables.

See [CPI_from_cffDNA](CPI_from_cffDNA/) for detailed instructions.

### CPI_postnatal

Trio-based Combined Paternity Index (CPI) calculation using mother, child and putative father samples.

The module supports both DNP-based and SNP-based analyses, with configurable inclusion of maternal and child genotype combinations, minimum coverage and mismatch probabilities.

See [CPI_postnatal](CPI_postnatal/) for detailed instructions.

### Fetal_sex

Fetal sex determination from maternal plasma cfDNA using autosomal DNPs, X-chromosomal DNPs and Y-chromosomal SNPs.

The module evaluates the relative mean read support across autosomal and sex-specific markers and calculates three ratios for fetal sex classification.

Marker selection and classification thresholds are configurable. The analysis does not require a putative father sample.

See [Fetal_sex](Fetal_sex/) for detailed instructions.

### contamination

Tools for contamination assessment and related quality-control analyses.

See [contamination](contamination/) for detailed instructions.

### SNPcall

SNP-calling workflow adapted from DNPcall while preserving its filtering criteria and read-to-marker association strategy.

SNPcall generates per-site allele counts for downstream SNP-based analyses, including paternity testing and Y-chromosomal marker analysis.

See [SNPcall](SNPcall/) for detailed instructions.

### DNP_error_rate

Standalone module for estimating single-base and double-base error rates in DNP sequencing data.

This analysis supports the characterization of sequencing errors and the methodological framework described in the associated publications.

See [DNP_error_rate](DNP_error_rate/) for detailed instructions.

## Requirements and Usage

Each module can be executed independently.

Module-specific requirements, input formats, parameters, execution commands and examples are provided in the corresponding directories.

DNP calling is performed using [DNPcall](https://github.com/lpistacchia/DNPcall).
