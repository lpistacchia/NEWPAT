# Fetal sex determination

This NEWPAT module estimates fetal sex from maternal
cell-free DNA (cfDNA) using autosomal and X-chromosome DNPs
generated by [DNPcall](https://github.com/fravasini/DNPcall)
and Y-chromosome SNPs generated by [SNPcall](../SNPcall).

The methodology is described in D'Atanasio et al. (2026),
[Genome Research](https://doi.org/10.1101/gr.281702.125).

## Requirements

- R
- R packages: optparse and dplyr

## Inputs

- Autosomal DNPcall output from maternal cfDNA.
- X-chromosome DNPcall output from maternal cfDNA.
- Y-chromosome SNPcall output from maternal cfDNA.
- Optional X-DNPcall outputs from male genomic DNA controls.

Use non-pseudoautosomal X markers and Y-specific markers.

## Method

Autosomal and X-chromosome informative sites are selected
using the same criteria as the prenatal CPI module:

- REF allele fraction >= 0.90 or <= 0.10.
- Other read fraction <= 0.10.
- At least 2 non-maternal reads by default.

MFF_A and MFF_X are the mean numbers of non-maternal
reads across informative autosomal and X-chromosome
sites, respectively.

MFF_Y is the mean number of REF + ALT reads across
all Y-chromosome markers, including uncovered markers.

## Fetal sex determination

| Ratio | Formula | Female | Male |
|---|---|---|---|
| A | MFF_X / MFF_A | >= 0.5 | < 0.5 |
| B | MFF_Y / MFF_A | <= 0.1 | >= 1 |
| C | MFF_Y / MFF_X | <= 0.1 | >= 2 |

Fetal sex is assigned when all three ratios support
the same classification. Otherwise, the result is
reported as Undetermined.

These numerical thresholds are configurable operational
defaults implemented in NEWPAT.

## X-chromosome specificity control

X-DNP specificity can optionally be assessed using
male genomic DNA controls.

By default, a marker is excluded when its minor allele
fraction exceeds 0.01 in at least two male controls
with REF + ALT coverage >= 100.

Unevaluated markers are retained by default and can
optionally be excluded using --exclude_untested_X.

A predefined exclusion table can also be supplied
using --exclude_X, with columns chr, pos1, pos2,
REF and ALT.

## Usage

    Rscript Fetal_sex.R \
      --autosomes autosomal_DNPcall.txt \
      --X X_DNPcall.txt \
      --Y Y_SNPcall.txt \
      --out results

## Optional parameters

| Argument | Description | Default |
|---|---|---|
| --min_fetal_reads | Minimum non-maternal reads | 2* |
| --min_fetal_percent | Minimum non-maternal read percentage | Inactive |
| --male_controls | File listing male X-DNPcall outputs | Inactive |
| --exclude_X | Predefined X-marker exclusion table | Inactive |
| --exclude_untested_X | Exclude unevaluated X markers | FALSE |
| --min_male_depth | Minimum male REF + ALT coverage | 100 |
| --max_minor_fraction | Maximum minor allele fraction | 0.01 |
| --min_males_failed | Minimum number of failing controls | 2 |
| --A_threshold | X/autosome threshold | 0.5 |
| --B_female_max | Maximum female Y/autosome ratio | 0.1 |
| --B_male_min | Minimum male Y/autosome ratio | 1 |
| --C_female_max | Maximum female Y/X ratio | 0.1 |
| --C_male_min | Minimum male Y/X ratio | 2 |

*The default of 2 reads applies when neither fetal-read
filter is specified. When both filters are supplied,
both thresholds must be satisfied.

## Examples

The [example inputs](examples/inputs) contain synthetic
read-count tables for 20 autosomal DNPs, 10 X-DNPs
and 10 Y-SNPs.

Two male genomic DNA controls illustrate X-marker
specificity assessment.

Run from the Fetal_sex directory:

    for sex in Female Male; do
      Rscript Fetal_sex.R \
        --autosomes "examples/inputs/${sex}_autosomes.txt" \
        --X "examples/inputs/${sex}_X.txt" \
        --Y "examples/inputs/${sex}_Y.txt" \
        --male_controls examples/inputs/male_controls.txt \
        --exclude_untested_X \
        --out "results_${sex}"
    done

### Example results

| Sample | MFF_A | MFF_X | MFF_Y | A | B | C | Fetal sex |
|---|---|---|---|---|---|---|---|
| Female | 20 | 20 | 0 | 1 | 0 | 0 | F |
| Male | 20 | 2.5 | 30 | 0.125 | 1.5 | 12 | M |

- [Female example outputs](examples/outputs/Female)
- [Male example outputs](examples/outputs/Male)

These synthetic examples illustrate software functionality
and are not intended for analytical validation.

## Outputs

| File | Description |
|---|---|
| Fetal_sex_summary.txt | MFF values, ratios, classification and parameters |

| X_informative_sites.txt | Selected X-DNPs |
| Y_sites.txt | Y-SNP read counts |
| X_excluded_markers.txt | Excluded X-DNPs |
| X_specificity_QC.txt | Specificity assessment when male controls are provided |
